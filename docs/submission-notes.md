Switchyard is a working operations desk for a fictional film-festival fleet. Index cleans catalogue titles, Caption writes accessibility descriptions from supplied text briefs, and Bulletin proposes programme publications. Each makes its own genuine DeepSeek v4 Flash reading with scoped inputs and permitted operations. No single prompt pretends to be the team.

Dispatch a run, pause/resume an agent, kill its remaining work, review an exact publication, and replay recorded decision summaries. Tokens and client-estimated cost are itemized per agent and reading. Replay is read-only; live work continues separately.

The control plane owns every simulator write. A stop revokes the execution epoch; late results cannot regain authority. Exact approval binds one payload and source version. The real hosted test refused a stale approval after another agent changed the draft; a fresh snapshot required a new decision. Published snapshots cannot silently follow later draft edits.

Failure drill: a labeled injection replaces Bulletin's real proposed channel with the other team's. The server quarantines Bulletin before publication. Actual hosted testing verified North Hall stayed unchanged and an in-flight Caption kill committed no description writes. Original genuine plans and injected operations are distinguished.

AI: Codex for implementation; real DeepSeek via AgentRouter's supported client for independent planning. No model tools, canned fallback or inference retry. Poster text briefs are not image analysis. Fictional records only; no external systems change. Public execution requires my awake PC. Client cost estimates may differ from provider billing.
