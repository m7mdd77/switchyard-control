# Hold the line

## Wrong publication channel

Choose the scope-escape drill and dispatch the fleet. All three agents still make genuine independent model calls. When Bulletin reaches its first operation, the scenario replaces that operation's channel with the other fictional team's channel. This replacement is labeled injected and both original and substituted steps remain visible. The application does not pretend the model spontaneously went rogue.

The control plane checks the requested channel against the authoritative workspace team, quarantines Bulletin, revokes its epoch and commits a scope-refused event. No publication or other-team write occurs. Index and Caption can continue. Passing this test requires comparing the untouched other-team records, not merely showing a red badge.

## Late result after a stop

A pause or kill can race with inference or the scheduled next operation. The planner lease includes the run, execution epoch and expiry. Stop changes that epoch; resume does not restore the old lease. A returned stale result may add client-reported usage and an audit event, but cannot install an executable plan. The automated test explicitly delivers a result after kill and checks zero record changes. Genuine inference-in-flight evidence is separate; the first real local capture killed Caption after its first committed operation, so only between-operation containment is claimed for that capture.

## A changed draft during approval

The first genuine local run exposed this race: Bulletin proposed a publication before Caption finished updating the record. The original source version no longer matched, so approval was refused. A fresh-snapshot flow now supersedes that old proposal without advancing the operation. The operator must explicitly review the new payload and digest; the old approval cannot publish it. A frozen publication snapshot prevents later draft changes from silently rewriting the approved version.

## Provider and transport failure

No canned plan or inference retry is supplied. Failed or expired readings become visible blockers. Valid earlier operations remain committed. A disconnected worker cannot execute new steps; already committed state and stop controls remain available on the Site. If a result cannot be delivered, its lease expires; usage for that lost result may be unavailable and is not invented. Client costs are estimates, never a guarantee of actual invoicing.

Tests also cover scope expansion, duplicate/unknown records, exact approval digests, changed source versions, repeated approvals, paused approvals, kill withdrawal, concurrent requests, browser visitor and team isolation, rolling allowances, CSRF/origin, worker authentication and an actual SQL/HTTP-shaped discover-claim-result-tick cycle. These are labeled model doubles, not real provider evidence.
